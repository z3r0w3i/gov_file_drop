# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.0 – 2026-10-05

### Added
- Initial release of Gov File Drop for Nextcloud 27 through 36.
- Secure government and enterprise document submission portal template.
- Pre-submission file review queue with size formatting and item deletion.
- Legal compliance terms agreement box adhering to Law No. 91/2025/QH15.
- Native WebDAV XHR sequential upload pipeline with percentage progress indicators.
- Automatic privacy shielding for applicant confidentiality (hides existing files from public).
- Autonomous `IPublicShareTemplateProviderWithPriority` integration.
